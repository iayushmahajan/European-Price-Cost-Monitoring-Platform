# Portfolio screenshots

Six real-application captures, each 1440 × 900. Run `npm run screenshots` from `frontend/` with the populated Docker application running. Set `SCREENSHOT_BASE_URL` or `PORTFOLIO_ANALYSIS_ID` to select another live deployment or existing successful record. The script refuses write requests and never submits a model query.

- [home.png](home.png) — Page introduction and primary workspace
- [overview.png](overview.png) — Page introduction and primary workspace
- [explore.png](explore.png) — Page introduction and primary workspace
- [sources.png](sources.png) — Page introduction and primary workspace
- [fuel-comparison.png](fuel-comparison.png) — Historical comparison canvas
- [analyst.png](analyst.png) — Restored analytical result

The Analyst capture focuses on a genuine saved result, with its historical assessment date retained. Fuel prices, inflation and currency rates refer to their displayed observation periods; these images are not claims about today's prices. Source warnings remain visible. Metadata is in [capture notes](capture-notes.json).
